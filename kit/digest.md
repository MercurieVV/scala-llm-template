This project carries the reengineering kit: the vendored `AllowedShape` scalafix rule, the build wiring that puts it on a shaped module's tool classpath, and the five process skills under `.dsh/skills/`. The rule is configured by the keys `allowedTypes` and `disallowedConstructs`, and the enforcement README — `kit/arhitecture-shape/README.md` in scala-llm-template, `arhitecture-shape/README.md` where the scala-cli wiring vendored it — states the config schema, the symbol-prefix semantics and the rule's named blind spot; this block restates none of them. The five skills are `shaping-a-module`, `reengineering-module`, `reshaping-module-by-linters`, `verify-before-done` and `verification-lane`, and the canonical `R-1 … R-14` rule list they cite lives in the `scala-coding-guidelines` wiki at `/Users/viktorskalinins/IdeaProjects/my/scala-coding-guidelines/wiki/reengineering/reengineering-contract.md`.
