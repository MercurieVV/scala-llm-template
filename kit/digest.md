This project carries the reengineering kit: the vendored `AllowedShape` scalafix rule, the build wiring that puts it on a shaped module's tool classpath, and the six process skills under `.dsh/skills/`. The rule is configured by the keys `allowedTypes` and `disallowedConstructs`, and the enforcement README vendored with the wiring (`.kit/arhitecture-shape/README.md`) states the config schema, the symbol-prefix semantics and the rule's named blind spot; this block restates none of them. The six skills are `shaping-a-module`, `reengineering-module`, `reshaping-module-by-linters`, `verify-before-done`, `verification-lane` and `vericoding`, and the canonical `R-1 … R-14` rule list the first five cite lives in the `scala-coding-guidelines` wiki at `wiki/reengineering/reengineering-contract.md` (`/Users/viktorskalinins/IdeaProjects/my/scala-coding-guidelines/wiki/reengineering/reengineering-contract.md` on this machine).
